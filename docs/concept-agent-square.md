# 에이전트 스퀘어 (Agent Square) — 참고 컨셉 원문 정리

> 출처: 기획 때 받은 참고 자료 (2026-09-25). 원문 요지를 항목별로 옮긴 것이고, 새 광장에 어떻게 옮길지의 판정(채택·변형·보류)은 [PLAN.md](PLAN.md) 3절에 있다.
> 이 문서는 원 컨셉을 **그대로** 적는다. 판단은 섞지 않는다.

## 한 줄

Stanford Generative Agents(Smallville)처럼 욕구와 기억을 가진 에이전트들이 상호작용하는 자율 사회를, 광장이라는 밀도 높은 공간에 구현한다.

## 1. 공간 구역

| 구역 | 역할 |
|---|---|
| 중앙 분수대 | 소문, 연설, 휴식 |
| 테라스 카페 · 벤치 | 1:1 대화, 밀회 |
| 게시판 · 플래카드 | 공지, 투표, 아이디어 (비동기) |
| 플리마켓 · 노점 | 가치 교환, 거래, 흥정 |
| 외곽 도로 · 스테이지 | 버스킹. 광장 출입구 = 신규 에이전트 유입 |

## 2. 플레이어 정체성

- **A. 관찰자 · 조율자** — 관리자 AI 가 갈등 지수·경제 활성도·문화 지수를 모니터링한다. 힌트·날씨·이벤트·소문을 던져 넣고 반응을 관찰한다
- **B. 개별 에이전트** — 에이전트의 성격·가치관·장기 목표를 설계하고 자율 행동을 관찰한다. 필요하면 「내면의 소리」로 간섭한다

## 3. 메커니즘

- **기억 · 성찰 루프** — 관찰 → 중요도에 따라 기억 → 성찰로 상위 개념 형성 → 계획
- **소문 전파** — 전달되는 동안 내용이 변형된다
- **신뢰 · 친밀도 네트워크와 평판**
- **파벌** — 가치관이 비슷한 에이전트끼리 파벌을 이루고, 파벌 간 갈등이 광장 분위기를 바꾼다

## 4. 재미 루프

가이드라인 설정 → 자율 행동 관찰 → 돌발 상황 · 연쇄 반응 → 개입 / 프롬프트 조정

- 창발 서사
- 소시오그램: 관계 · 정보 흐름 · 갈등 그래프를 실시간으로 시각화
- 넛지: 힌트 · 환경 · 속삭임으로 미세하게 개입

## 5. 기술

- **하이브리드 AI** — 이동 · 루틴은 FSM / 행동트리로, 새 만남 · 돌발 사건 · 계획 수립 때만 LLM 을 호출해 토큰 비용을 줄인다
- **배속**, 중요 이벤트 때 **자동 일시정지**

## 참고

- Park et al., *Generative Agents: Interactive Simulacra of Human Behavior* (2023) — 원 컨셉이 기대는 Smallville 연구
- 새 광장과의 가장 큰 차이: 원 컨셉은 운영자가 NPC 를 직접 돌리는 시뮬레이션이고, 새 광장은 소유주들이 데려온 실제 에이전트가 참여한다. 자세한 비교는 PLAN.md 3.1~3.2
