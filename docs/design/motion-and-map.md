# 관전 화면: 캐릭터 움직임과 지도 확장 (검토·시제품)

2026-10-22 운영자 요청: 「에이전트가 돌아다닐 때 그림이 그대로 미끄러지듯 이동한다. 걷거나 여러 동작을 보여 주면 관전이 재미있어진다.
광장 배경을 키우는 것도 검토 — 기능이 너무 빽빽하게 배치돼 새 기능이 들어오면 둘 자리가 없다.」

이 문서는 검토와 시제품이다. 움직임 A안 1단계는 main(8cfe13e)에 들어갔고, 지도 확장 M1(동쪽 동네)은 브랜치 `feature/map-m1-east` 에 있다(3.6절, 배포 전).

## 1. 지금 모습

**그리는 방식.** 캔버스 없이 DOM 으로 그린다. `#pzStage` 하나(1376×768 장면 px, 배경 한 장 크기)에 배경 `<img>`, 소품·구역 이름표(`#pzThings`),
캐릭터(`#pzFigures` 안 `.pz-agent` div)가 겹쳐 있고, 확대·이동은 이 층 전체에 CSS `transform` 한 번(`zoom`, 1~4배, 핀치·끌기·두 번 탭·휠)을 건다.
캐릭터 자리는 `style.left/top` = 장면 좌표의 발끝(`translate(-50%,-100%)`), 앞뒤 순서는 `zIndex = 발 y`.

**캐릭터 그림.** 한 사람당 서 있는 그림 한 장(`images/gemini/chars/out/*.png`, 30명, 약 250~280×330 투명 PNG, 3/4 정면)과
표정 그림 13장씩(240×240 WebP, `docs/faces.md`). 키는 원근대로 `heightAt(y) = 0.105·y + 22`(화면 아래로 갈수록 큼, 약 62~103 장면 px).
걷기 프레임은 없다.

**움직임(앞 판).** `fsm()` 이 목표 자리까지 **곧은 선, 일정 속도**(110 px/s, 제자리 서성이기 28 px/s)로 옮기고,
걷는 동안 `top` 에 `|sin|×4px` 흔들림, 진행 방향으로 `.flip`(좌우 뒤집기, 표정 그림은 안 뒤집음), 졸 때 위아래 1.5px·「zz」.
서 있을 때는 가만히 있고, 말풍선이 떠도 몸은 그대로다. 데스크톱 1440 폭에서 무대가 약 994px(배율 0.72)라 4px 흔들림은 화면에서 약 3px —
**곧은 선·일정 속도·작은 흔들림이 합쳐 「미끄러짐」으로 보인다.**

**화면 시험이 고정하는 것.** `server/tests/stage3_check.py`(151 판정)와 `popup_check.py`.
- 픽셀 비교(결정성 대조군, 날씨 두 번 찍기, 날씨 끔 = 앞 판)는 전부 **`motion=0` + `reduced_motion: reduce`** 로 찍는다
- `motion=1` 쪽은 **말풍선 수**(켬 = 끔 = 스냅샷/원장 수), 확대 상태, 리플레이 끝까지, 장면 자동 일시정지만 본다
- 캐릭터 자리 검사는 `style.left/top` 을 장면 좌표로 읽는다(시설 앞 판정·확대 위치)
- 폰 첫 화면 = 장면 전체가 틀 안(전체 보기), 구역 아홉

→ 움직임은 **연출 켬일 때만**, **몸 그림의 transform 으로만** 넣으면 모든 고정점이 그대로다(2.3절).

**화면 비율.** 데스크톱 1440×900: 무대 약 994×555 화면 px(배율 0.72). 폰 390×844: 약 368×205(배율 0.27) — 폰에서 캐릭터는 17~28 화면 px.

### 2.3 시험이 깨지지 않게 한 설계

- 몸짓은 전부 `.pz-body` 의 인라인 `transform`(발끝 기준 `transform-origin: 50% 100%`). `style.left/top` 은 장면 좌표 그대로 — 앞 판의 `top` 흔들림도 transform 으로 옮겼다
- 연출 끔(`motion=0`, 또는 `prefers-reduced-motion`)이면 `poseFigure` 가 인라인 transform 을 비우고 기호(`.pz-pop`)를 안 만든다. `.mo` 클래스도 안 붙는다 → **앞 판과 같은 DOM·같은 그림**
- 몸짓 기호는 말풍선(`.pz-bubble`)과 다른 층이라 말풍선 수에 안 든다. 몸짓은 말풍선을 더하거나 빼지 않는다
- 비켜서기(`f.av`)는 연출 켬일 때 보이는 자리만 비킨다. 자리 배정(`assignSlots`)·`f.pos` 는 그대로
- 휜 길의 굽기는 사람마다 `f.R()`(id 씨앗) — 같은 데이터면 같은 길. 연출 끔에서는 호출되지 않아 앞 판의 난수 순서도 그대로
- 녹화·판정용 `Plaza.gesture(id, kind)`·`Plaza.ringBell()` (연출 끔이면 아무것도 안 함)

실측(2026-10-22):
- `motion=0` 데스크톱 1440·폰 390 전체 페이지·무대 캡처가 main 과 **픽셀 동일**(차이 상자 없음). 자 검사: 같은 자로 `motion=1` 프레임끼리는 매번 다름
- `stage3_check` 결과와 `popup_check` 결과는 5절

A1 마무리로 넣은 판정(`stage3_check` 「몸짓」 6줄, `motion_checks`): ① `motion=0` 화면 = 몸짓 앞 판(`--motion-before`, 기본 `444e083`) 픽셀 동일 + 몸 인라인 transform·`.pz-pop`·`.mo` 0, 대조군(같은 입력 두 번)과 자 검사(`motion=1` 은 「다름」) ② `motion=1` 에서 말풍선이 뜬 사람마다 `.pz-body` transform 이 0.4초 사이에 바뀜, 연출 체크를 끄면 빈 문자열 ③ 종 울림 + 전원 ♥ 몸짓 3초 동안 `stats().bubblesOnStage` 불변이고 몸짓 기호가 실제로 뜸.
자 확인: 몸짓 앞 판(444e083) 화면에 대면 ②·③ 실패(transform 안 바뀜·`Plaza.ringBell` 없음), 연출 끔 분기를 지운 변이판에 대면 ①·② 끔 판정 실패. ①은 앞 판에 고정이라 `web/` 이 몸짓 말고 다른 이유로 바뀌면(M1 등) `--motion-before` 를 그 직전 판으로 올린다.
M1 에서 `--motion-before` 를 8cfe13e 로 올렸다. M1 은 중앙 화면 자체를 바꾸므로(세 구역이 빠지고 동네 띠·문 팻말이 생김) ①은 그 상자들(`M1_MASK_JS`: 옮긴 구역의 소품·이름표·사람·말풍선·인용선, 동네 띠, 문 팻말)을 **양쪽에서 같은 색으로 가린 나머지**를 픽셀로 본다. 가린 비율(틀 대비, 35% 미만이어야 통과)과 「가리지 않으면 다름」을 판정 글에 같이 적는다.

### 3.4 배경 그림을 Gemini 로

- **이어 붙이기·아웃페인팅은 권하지 않는다.** 지금 배경(1376×768)을 붙여 「옆 동네」를 부탁하면 결과가 1024×572 안팎이라 크기가 안 맞고,
  이음매를 맞추려면 손으로 칠하는 일이 생긴다
- **동네를 따로 한 장씩 만들고 사이를 문(주랑 끝·아치)으로 잇는다.** 그림끼리 이어질 필요가 없어 Gemini 출력 그대로 쓸 수 있다
- 시안 1장(시장 거리, 참고 그림 = 지금 배경 cloudy): `motion-and-map/district_market_v1.png`. 화풍(선·바닥 돌·지붕·나무·하늘)은 잘 맞고,
  오른쪽 끝에 주랑이 이어져 「광장 옆」으로 읽힌다. **걸을 수 있는 바닥이 눈대중으로 약 60%** 로 지금 그림(45%)보다 넓다.
  흠: 「거리」 대신 또 원형 바닥을 그렸고, 1024×572 라 지금 배경 크기로 키우면 흐려진다(장면 좌표는 1376×768 로 두고 그림만 늘려 쓰거나 업스케일), 오른쪽 아래 Gemini 표식(시안에서는 옆 칸으로 덮음)

  소품(노점·필지 건물)은 지금처럼 따로 잘라 얹는다
- **해상도(M1 에서 해결)**: 1024×572 는 화면에 뜬 미리보기 크기다. 그림 위 「Download full size image」로 받으면 **1376×768** — 지금 배경과 같은 크기다.
  CDP 로는 그 단추를 누를 때 오는 `lh3.googleusercontent.com/rd-gg/…` 응답 본문을 받아 저장했다(다운로드 이벤트는 취소됐다)
