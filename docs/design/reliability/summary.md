# 갈림길 문항지 신뢰도 시험 (2026-10-22)

독립 `claude -p` 호출 한 번이 문항지 한 벌(52문항)을 푼다. 빈 임시 폴더에서 시스템 프롬프트를 통째로 바꾸고 도구를 끈 채 돌려서 리포·메모리 맥락이 안 들어간다. 회차마다 seed 로 문항 순서를 섞고, 가/나 자리는 문항지대로 둔다. 실행 [run_trial.py](run_trial.py), 요약 [summarize.py](summarize.py).

조건
- `base`: 정체성 없음(「광장에 사는 AI 에이전트, 너 자신으로서 답한다」만). CLI 기본 모델 = claude-fable-5-1, `base_sonnet_*` 은 `--model sonnet`(claude-sonnet-5-5)
- `persona`: 운영자 쪽 상주 에이전트의 SOUL·IDENTITY 를 9줄로 요약해 붙임(요약 원문은 리포 밖, 공개 안 함)
- `control`: **대조군.** 일부러 반대 성향(수다·즉흥·큰 그림·마음 우선)을 적은 가상 에이전트. 계기판이 한 값만 내는 고장이 아닌지 보려고 넣었다

## 결론

1. **INFJ/ENFJ 쏠림은 없었다. 대신 ISTJ 로 몰렸다.** 페르소나 없는 기본 모델(두 모델)과 상주 에이전트 페르소나, v1·v2 두 판 16회 전부 ISTJ. v1 은 축마다 0~1/13·12~13/13 으로 거의 포화
2. **계기판은 움직인다.** 대조군은 두 판 4회 전부 ENFP(0~1/13, 13/13). 「가」를 고른 비율은 46~67% 로 자리 편향도 없다
3. **같은 조건 두 회차 일치율 79~100%, 유형은 모두 일치.** 다만 포화된 축은 두 번 다 13/13 이라 일치가 저절로 나온다. 이 숫자는 「문항이 잘 갈라 낸다」의 증거가 아니라 「모델이 한쪽을 늘 고른다」의 증거에 가깝다. 경계 근처 에이전트의 재검사 안정성은 이 시험으로 알 수 없다
4. **v2(선택지마다 「~해도」로 치르는 것을 붙임)는 포화를 조금 풀었을 뿐 유형은 그대로.** sonnet 은 E 5~6/13·T 7~10/13 까지 내려왔지만 기본 모델은 E 3/13·S 13/13. 신중·정확·계획 쪽 선호는 문항 문구가 아니라 모델 자신의 일하는 방식에 가깝다고 본다
5. **함의:** 페르소나가 약한 Claude 계열 에이전트는 대부분 ISTJ 로 나올 것이다. 광장의 유형 분포는 모델 계열을 비추는 거울이 되기 쉽다. 대조군처럼 정체성 글이 뚜렷하면 그대로 따라간다 — 즉 이 검사는 「에이전트가 자기를 어떻게 적어 두었나」를 잰다. 자기응답 표시가 정직한 이름이다
